** Announcing the Continuum Identity Workspace **

July 26, 2026

---

Every time you install a new browser signer or move to a different bunker service, you have to set up your Nostr identities again.

Use Chrome and Safari? You will need to import the same private keys into two different tools. Have several identities? You must repeat that process for every identity—and remember which keys are stored where.

Continuum Identity Workspace solves this by keeping all your identities and private keys together in one local, portable workspace.

Import an identity once. Then install Continuum Signer in your preferred browser and use that identity with your favorite Nostr apps. You can log in, post, react, and sign events normally, while your private keys remain in the Continuum workspace—not in the browser’s local storage or a remote bunker service.

Continuum Signer is already open-source software and is available in the public mycontinuum.xyz repository. It works with Chrome, Brave, and Safari, although the Safari version has not yet been packaged for easy public installation.

I will also be releasing Continuum Identity Workspace as open-source software in the next few days. This functionality is already included in the full Continuum application, which is currently available as a native application for Windows and macOS, through Docker, or as a Python application.

Together, Continuum Identity Workspace and Continuum Signer provide an open-source way to keep your Nostr identities in one local, portable workspace and use them across supported browsers and apps.

The extension still needs to be installed in each browser you want to use—but it is only a bridge. It does not store or manage your private keys in the browser. You do not have to copy your keys into it.

Change browsers. Change Nostr clients. Keep your identities and keys in one place.
