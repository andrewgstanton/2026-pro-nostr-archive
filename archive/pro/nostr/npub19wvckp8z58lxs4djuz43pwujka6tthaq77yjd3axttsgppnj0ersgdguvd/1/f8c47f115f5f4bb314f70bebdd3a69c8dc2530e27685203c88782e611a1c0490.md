You can import a workspace you backed up from another machine

Server A-> backup (zip file) put it on a thumb drive 

Server B import the zip file

Now server B (running continuum) has the same workspace as Server A
 
You would still need to install the signer extension into  each browser (in the new machine)  but you have to that now anyway
